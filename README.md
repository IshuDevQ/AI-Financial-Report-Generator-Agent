

# AI Financial Report Generator Agent

I built this project as a Python-based AI financial reporting agent that can automatically generate a structured financial report for a publicly listed company. The project combines financial data collection, basic market analysis, financial statement extraction, chart generation, PDF report creation, and local AI-based explanation using Llama through Ollama.

The main idea behind this project is to reduce the manual effort required to prepare a basic company financial report. Instead of manually collecting stock prices, calculating returns, creating charts, and writing summaries, this agent performs those steps automatically and generates both Markdown and PDF reports.

## Scope of the Project

The current scope of the project is focused on public companies whose data is available through Yahoo Finance. Given a stock ticker such as `AAPL`, `MSFT`, or `TSLA`, the agent fetches market data, calculates important indicators, extracts company-level financial highlights, creates visual charts, and writes a report.

This project is not designed to give investment advice. It is meant for educational, analytical, and portfolio-building purposes. The report generated by the system should be treated as an automated financial summary, not as a buy, sell, or hold recommendation.

## What This Project Does

The project currently performs the following tasks:

- Takes a stock ticker as input from the user.
- Fetches historical stock price data using `yfinance`.
- Retrieves company information such as company name, sector, industry, country, website, and business summary.
- Calculates stock-related metrics such as latest closing price, 7-day return, 30-day return, daily volatility, 20-day moving average, and 50-day moving average.
- Fetches company financial statement highlights such as revenue, net income, total assets, total liabilities, operating cash flow, free cash flow, profit margin, and debt-to-assets ratio.
- Generates stock price and moving average charts using `matplotlib`.
- Creates a Markdown financial report.
- Creates a formatted PDF financial report.
- Uses a local Llama model through Ollama to generate an AI-written financial analysis.

## How the Agent Works

The workflow of the project is simple:

```text
User enters stock ticker
        ↓
Fetch stock price data
        ↓
Fetch company information
        ↓
Calculate market metrics
        ↓
Fetch financial statement highlights
        ↓
Generate charts
        ↓
Generate local AI financial analysis
        ↓
Create Markdown and PDF reports
```

For example, if the user enters:

```text
AAPL
```

the agent generates a report for Apple Inc.

## Installation

First, clone the repository:

```bash
git clone <your-repository-url>
cd Finance_Report
```

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Ollama Setup

This project uses a local Llama model through Ollama for AI-generated financial analysis.

Install Ollama first, then pull the Llama model:

```bash
ollama pull llama3.2:3b
```

Make sure Ollama is running:

```bash
ollama serve
```

In another terminal, you can check whether the model is available:

```bash
ollama list
```

## How to Run the Project

From the main project folder, run:

```bash
python app.py
```

Then enter a stock ticker when prompted:

```text
Enter stock ticker, for example AAPL, MSFT, TSLA: AAPL
```

You can also enter a period such as:

```text
1mo, 3mo, 6mo, 1y
```

If you press Enter without typing a period, the default period is `6mo`.

## Current Limitations

- The project depends on data availability from Yahoo Finance.
- The AI-generated analysis is based only on the data passed into the prompt.
- The model does not perform independent financial research.
- The report should not be treated as professional financial advice.
- The quality of the AI-written section depends on the local model used.
